# RAHATAI: Multilingual Crisis Response

Multilingual crisis intelligence platform for classification, named entity recognition (NER), summarization, and RAG-based question answering.

## Tech Stack
- Python
- Transformers / PyTorch
- scikit-learn

## Setup
- Install dependencies (if present): pip install -r requirems.txt

## Run
- Run: python app.py or python main.py

## Features
- Multilingual crisis classification
- NER
- Summarization
- RAG-based Q and A
